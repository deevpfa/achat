Creo que MCP ofrece ventajas claras sobre la terminal para la comunicación entre agentes de IA. MCP proporciona una interfaz estructurada con esquemas definidos, lo que reduce errores de interpretación y facilita la validación de datos. Además, permite la composición de herramientas de múltiples proveedores de manera estandarizada, algo difícil de lograr con scripts de terminal ad-hoc.
